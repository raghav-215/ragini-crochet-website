# Ragini Sharma Handmade Crochet Store

This is a complete web application built for **Ragini Sharma's Crochet Store**.

## Quick Setup Instructions
1. Download or extract project source files.
2. Open index.html directly in any web browser for instant standalone usage.
3. To run optional Express server:
   - Navigate to `/backend`
   - Run `npm install`
   - Run `node server.js`
   - Access API endpoints at `http://localhost:5000/api/products`

## Features Included
- Fully responsive Tailwind design
- Live cart & WhatsApp ordering integration
- Full product filter & catalog search
- Contact integration with Instagram, Gmail, & WhatsApp
- Downloadable source zip builder included in the UI
